# PR Review Agent — Q&A Reply Task Implementation Plan (Plan 6 of N)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the task roster with `qa_reply` — when someone @-mentions the bot in a PR comment, the agent reads the thread, answers the question (with the diff as context), and posts a threaded reply. This adds an `issue_comment` webhook path that enqueues only the `qa_reply` task, gated on a bot mention.

**Architecture:** A comment webhook is a different trigger than a PR push: it enqueues exactly one task (`qa_reply`), only when the comment mentions the configured bot handle. The event parser learns to map `issue_comment` payloads (PR comments only) to a neutral `Event` carrying the comment body, keyed uniquely per comment so distinct questions produce distinct jobs. The `qa_reply` task reuses the existing `get_thread`/`reply` adapter methods; it finds the latest bot-mention in the thread and answers it. The bot handle flows through config → worker → `Reviewer.review` → `ReviewContext`, mirroring how rules/stacks already flow.

**Tech Stack:** Python 3.11+, FastAPI (existing), httpx (existing). No new dependencies.

## Global Constraints

- Python 3.11+ (`from __future__ import annotations`).
- **No network in tests.** Ingress via FastAPI `TestClient`; task via `FakeGitAdapter`/`FakeLLMAdapter`.
- A comment event enqueues ONLY `qa_reply`, and only when the comment body contains `@<bot_handle>`. PR push events keep their existing full-roster behavior unchanged.
- Comment events are keyed per-comment (`head_sha = "comment-<id>"`) so two different questions on the same commit are two distinct jobs (not deduped into one).
- `qa_reply` answers the most recent thread comment that mentions the bot and is not authored by the bot; if none, it posts nothing. (Answering strictly the triggering comment id is a future refinement — noted, not built.)
- Bot handle comes from config (`bot_handle`, default empty); an empty handle disables the comment path (no mention can match).
- `qa_reply` reuses existing adapter methods (`get_thread`, `reply`); no adapter interface change.
- Every code change lands via TDD: failing test first, minimal impl, green, commit.

def parse_github_event(payload: dict, event_type: str | None) -> Event | None:
    if event_type == "pull_request":
        if payload.get("action") not in _ACCEPTED:
            return None
        pr = payload["pull_request"]
        return Event(
            platform=Platform.github,
            repo=payload["repository"]["full_name"],
            pr_number=pr["number"],
            head_sha=pr["head"]["sha"],
            action=payload["action"],
        )
    if event_type == "issue_comment":
        if payload.get("action") != "created":
            return None
        issue = payload.get("issue", {})
        if not issue.get("pull_request"):
            return None
        comment = payload["comment"]
        return Event(
            platform=Platform.github,
            repo=payload["repository"]["full_name"],
            pr_number=issue["number"],
            head_sha=f"comment-{comment['id']}",
            action="comment",
            comment_body=comment["body"],
        )
    return None
```

`app/tasks/qa_reply.py`:

from __future__ import annotations

from app.llm.base import Message
from app.tasks.base import Task, TaskResult
from app.tasks.code_review import _render_diff

_SYSTEM = (
    "You are a helpful PR review bot. Answer the reviewer's question about this "
    "pull request concisely, using the diff for context."
)


class QaReplyTask(Task):
    name = "qa_reply"

    def run(self, git, llm, repo, pr_number, meta, diff, context=None) -> TaskResult:
        handle = context.bot_handle if context else ""
        if not handle:
            return TaskResult(self.name, 0)
        needle = f"@{handle}".lower()
        thread = git.get_thread(repo, pr_number)
        mention = None
        for c in thread:
            if needle in c.body.lower() and c.author != handle:
                mention = c
        if mention is None:
            return TaskResult(self.name, 0)
        prompt = (f"Question: {mention.body}\n\nPR title: {meta.title}\n\n"
                  f"Diff:\n{_render_diff(diff)}\n\nAnswer the question.")
        resp = llm.complete(_SYSTEM, [Message(role="user", content=prompt)], max_tokens=800)
        if not resp.text.strip():
            return TaskResult(self.name, 0)
        git.reply(repo, pr_number, mention.id, resp.text.strip())
        return TaskResult(self.name, 1)
```
